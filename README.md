# 桌面宠物 (DesktopPet)

一只会呼吸、眨眼、散步的透明窗口小企鹅，常驻桌面。支持多动作动画、随机行为（待机/散步/开心连跳/睡觉/自言自语）、拖拽互动、定时喝水提醒、久坐/整点/下班提醒、自定义提醒事项、番茄钟、消息未读提醒（灵犀 / QQ / 微信 / 企业微信，持续未读超时跑到屏幕中心强提醒）。**1.2.0 新增** 提示音开关 / 免打扰时段 / 专注模式三件套静默控制、贴边隐藏、单击双击区分修复。**1.3.0 新增** 离开感知（锁屏静默 + 回来补报）。**1.5.0 新增** 番茄钟。**1.6.0 移除** 摸头互动（鼠标悬停蹭人），双击改为只跳 1 下。**1.7.0 新增** 右键菜单点选项不关闭、活跃度调节（睡觉占比 + 活动强度），贴边隐藏改为仅手动/提醒唤出，睡觉自动滑到边缘完整可见。**1.7.1 新增** 皮肤专属语音：feidudu 点击即播台词，活动时随机出声。

## 使用

直接双击 `DesktopPet.exe` 即可运行（首次运行会在用户目录 `~/.desktop_pet/` 写入配置与日志，免安装、无需 Python）。

操作：
- **拖拽**：按住左键拖动到任意位置
- **单击**：跳 1 下，偶尔说句话
- **双击**：跳 1 下 + 开心表情（laugh 帧持续 1.5 秒）+ 说句开心的话
- **右键宠物或托盘**：置顶 / 隐藏 / 开机自启 / 提示音 / 贴边隐藏 / 活跃度 / 各类提醒设置 / 专注模式 / 番茄钟 / 退出

> **1.6.0 起没有「摸头互动」了**。鼠标悬停在它身上不再有任何反应——这个功能
> 是 1.4.0 加的，实际用起来反馈层次跟双击撞车（光标路过就自己蹦一下，观感像
> bug），已整个移除。跳跃现在只有一个来源：**你真的动手点了它**（单击 / 双击）。

> **1.7.0 的右键菜单不会点一下选项就收起**——可以连着勾选/取消好几个开关，
> 再点菜单外空白处关闭。需要弹输入框的选项（自定义时间、活跃度等）会自动
> 收起菜单再弹窗。

### 开机自启

托盘右键 →「开机自启」勾选后，登录 Windows 时自动启动桌宠。原理是写入当前用户注册表启动项（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`），无需管理员权限；取消勾选即移除。仅打包版（exe）生效。

### 静默控制（1.2.0）

开会、写材料、夜间休息时不想被桌宠打扰？

- **提示音**（托盘勾选项）：关闭后所有提醒只弹气泡不响铃——开会共享屏幕时不再尴尬。
- **免打扰时段**（托盘子菜单）：预设（22:30-08:00 / 23:00-07:00 / 12:30-14:00）或自定义起止时间，支持跨零点。生效期间提醒只弹气泡，不响铃、不跳跃、喝水不跑到屏幕中心、IM 未读超时强提醒只在原地弹气泡。
- **专注模式**（托盘子菜单）：30 / 60 / 120 分钟。菜单标题实时显示「专注中 · 剩 X 分钟」方便看状态。专注期间同样完全静默，但有明确结束时间。

- **番茄钟**（1.5.0，托盘子菜单）：经典 25+5 循环（每 4 个 work 后长休 15 分钟）。阶段切换时桌宠会切表情（work → think 严肃，break → laugh 开心）+ 弹气泡。菜单标题显示「🍅 工作中 · 剩 X 分」/「☕ 休息中 · 剩 X 分」。与专注模式并存但独立——专注是任意时长静默，番茄是循环阶段静默。

→「免打扰时段」「专注模式」「番茄钟」可叠加使用（任一生效即静默）。

### 离开感知（1.3.0）

人不在电脑前时，桌宠不该继续空转提醒。开启后（托盘「离开时静默」，默认开）：

- **离开时**（Win+L 锁屏、屏保、休眠唤醒）：自动静默——不响铃、不跳跃、不跑到屏幕中心、不弹气泡，并暂停久坐计时（避免离开两小时后一回来就催你起身）。
- **回来时**：解锁后弹一条汇总（离开 ≥1 分钟才报，快速锁一下屏不打扰）：

  ```
  欢迎回来～你离开了 1 小时 30 分钟
  灵犀、微信 有未读消息；错过提醒：该吃药了、取快递
  ```

离开期间的消息按性质分类处理：

| 类型 | 离开期间 | 回来后 |
| --- | --- | --- |
| 自定义提醒事项（吃药/周会/取快递） | 记下来 | **补报**（超过 5 条折叠为「… 等 N 条」） |
| 周期提醒（喝水/久坐/整点/下班） | 丢弃 | 重新计时，不补报 |
| IM 未读 | 不逐条打扰 | 统一汇报哪些应用有未读 |

实现走 Windows 会话通知（`WTSRegisterSessionNotification` + `WM_WTSSESSION_CHANGE`），由系统主动推送，**零轮询开销**。离线、远程桌面断开等切换会话的场景同样适用。

### 贴边隐藏（1.2.0，1.7.0 改为手动唤出）

桌宠静止超过 30 秒自动滑到最近的屏幕边缘只露 20px（一角，避免长时间遮挡工作窗口）。托盘「贴边隐藏」勾选项可关闭。

**1.7.0 起**，隐藏后鼠标靠近**不会**再自动滑回——只有两种方式唤出：
- **点击露出的那条缝**（滑回你最近拖到的位置）
- **提醒到达**（收缝并原地提醒）

> 隐藏是给宠物"退到一边"用的，不是让它自己冒出来吓你一跳。收起期间它也不会
> 自己走动/跳起来从缝里溜出来，安安静静待着。

### 睡觉靠边（1.7.0）

桌宠睡着时会自己滑到最近的屏幕边缘**完整可见**地睡（不缩成缝，不挡窗口）。
醒来**睡在哪醒在哪**，不会回到睡前位置。若入睡时正好处于贴边隐藏状态则保持
原状不折腾。拖动按住睡着靠边的它即解除靠边，由拖动接管位置。

### 活跃度（1.7.0）

托盘右键 →「活跃度…」：滑块 0-100（默认 **50**，与旧版行为完全一致）。
活跃度同时调节桌宠的「性格」：

| 活跃度 | 睡觉占比 | 活动强度 |
| --- | --- | --- |
| 低（如 0-20） | 睡得久、清醒短、容易回睡，像只慵懒的猫 | 跳跃轻（14px）、步速慢（1px/帧），只有安静活动 |
| 中（50 默认） | 经典均衡节奏 | 经典跳跃（26px）与步速（2px/帧） |
| 高（如 80-100） | 睡得短、清醒久、几乎不赖床 | 蹦得高（最高 44px）、步速快（3px/帧）、散步/连跳更频繁 |

> 交互不受影响：单击/双击它永远是标准高度跳跃，回应不打折。

### 更换皮肤（1.1.0）

托盘右键 →「更换皮肤」：动态扫描 `assets/skins/` 下含全部动作帧的子目录，互斥单选，切换即时生效（保持窗口中心，托盘图标同步刷新），选择会持久化保存，重启后保留。

当前可用皮肤：
- **默认（企鹅）**：`assets/skins/` 根目录（原版，1.2.0 起补齐 drink/think/laugh 三个扩展帧）
- **feidudu（肥嘟嘟）**：`assets/skins/feidudu/`，9 个动作帧（含喝水/思考/笑等扩展帧）+ 专属台词

### 皮肤专属语音（1.7.1）

部分皮肤自带专属语音（WAV 文件），规则很简单：**`assets/sounds/{皮肤名}.wav` 存在即生效**，任何皮肤放上同名语音文件就自动有声，代码零改动。

- **点击即播**：单击 / 双击带语音的皮肤，100% 播放它的专属语音（无冷却，点一次响一次）。
- **活动随机播**：宠物自发进入 走路 / 跳跃 / 自言自语 / 散步 时，每次动作约 **20% 概率**随机出声，**15 秒内不重复**，避免动作频繁时语音连成噪音。贴边隐藏中不播。
- **静默控制**：免打扰时段 / 专注模式 / 关闭提示音时一律不响——语音跟其它提醒音同走一个静默开关，不会在你开会时突然冒一句台词。

当前带语音的皮肤：
- **feidudu（肥嘟嘟）**：`assets/sounds/feidudu.wav`（台词「你的胆子真是肥嘟嘟的」）

> 想给任意皮肤加声音：录一段 wav 放到 `assets/sounds/`，命名成皮肤名即可（如 `default.wav` 可给默认企鹅配音）。

### 宠物大小

托盘右键 →「宠物大小」：小 / 中 / 大 / 特大，或「自定义...」输入缩放系数（0.3~2.0，默认 0.65）。

### 喝水提醒

托盘右键 →「喝水提醒」：
- **开启提醒**：打开/关闭定时提醒
- **提醒间隔**：30 / 60 / 90 / 120 分钟，或「自定义...」输入任意分钟数
- **提醒位置**：跑到屏幕中心提醒 / 原地提醒

到点后：宠物跑到屏幕中心（或原地）→ 播放提示音 → 跳一下 → 弹出气泡提示随机喝水文案（5 秒后自动消失，宠物回到原位）。

### 消息未读提醒（灵犀 / QQ / 微信 / 企业微信）

托盘右键 →「消息提醒」子菜单：
- **开启消息提醒**：总开关，打开/关闭整个未读监听
- **灵犀 / QQ / 微信 / 企业微信**：各自的应用开关，可单独勾选

检测到某应用**有未读消息**时：桌宠跳一下 + 播放提示音 + 气泡提示「【应用】有新消息，快去看看吧」。

**持续未读超过 N 分钟**（托盘 → 消息提醒 → 超时强提醒，可选 1 / 2 / 3 / 5 分钟或自定义，默认 2 分钟）：桌宠**跑到屏幕中心**再提醒「消息还没看，快回来看看！」，之后按同样的超时时长重复提醒，直到你点开消息为止。

原理（不读取任何消息内容，只看任务栏状态）：
- 大多数 IM 桌面端收到新消息且窗口在后台时，会让任务栏图标「请求注意」，桌宠读取该状态；
- 部分应用（如 QQ）会在任务栏按钮/窗口标题显示未读角标（如「QQ (3)」），一并识别；
- 只判断「有没有未读」，拿不到未读数与消息内容（IM 不对外暴露）。
- 需应用在任务栏有按钮（运行中）；若某应用不提醒，查看日志 `~/.desktop_pet/logs/pet.log` 的「任务栏按钮名快照」行确认其按钮名。
- **自适应降频（1.2.1）**：有受监测 IM 在跑时 2 秒一轮；一个都没跑时自动降到 15 秒一轮，检测到应用启动立即恢复 2 秒。空闲时几乎不占 CPU，检测逻辑与结果完全不变。

> 另保留「飞书系统通知」监听（轮询 Windows 通知中心，识别来源为「飞书」的 toast，可显示消息摘要「【飞书】张三：你好」）。注意：**灵犀**（飞书定制版）不弹系统通知，只能走上面的任务栏未读方式；该通知监听对标准飞书客户端有效。首次使用若未开启通知访问，请到 Windows「设置 → 系统 → 通知」确认已开启。

### 其它提醒

托盘右键还可开启：**整点报时**、**久坐提醒**（30/45/60/90 分钟）、**下班提醒**（自定义时间）。

### 自定义提醒事项（1.2.0）

托盘右键 →「自定义提醒」子菜单，自加提醒事项：

- **每天固定时间**：如「15:00 该吃药了」
- **每周某天**：如「每周一 10:00 周会」（自动按周循环）
- **仅一次**：如「2026-09-01 16:00 取快递」（日期过了自动失效）

每项可临时停用（菜单里取消勾选），不会删除。桌宠到点提醒时与其他提醒一致：音效 + 跳 + 气泡（静默时段自动不响不跳）。

## 开发

```bash
# 创建 venv 并装依赖
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt

# 运行
.venv\Scripts\python main.py

# 打包为单 exe
build.bat
```

打包后产出 `dist/DesktopPet.exe`，可直接发给任何人双击使用。

## 换肤 / 加动作帧

皮肤目录结构：`assets/skins/` 根目录是默认企鹅皮肤；每个子目录（如 `feidudu/`）是一套独立皮肤，含以下动作帧：

- 基础 6 帧：`idle`(待机)、`blink`(闭眼)、`walk_a`/`walk_b`(走路)、`jump`(跳跃)、`sleep`(睡觉)
- 扩展帧（可选，按需加载）：`drink`(喝水)、`think`(思考)、`laugh`(笑)——皮肤目录里存在则启用对应动作，不存在时自动回退 `idle`，对其它皮肤零影响

制作要求：
- 所有帧需统一尺寸（建议 260×260、底部对齐、水平居中），否则切换会跳动
- 透明背景 PNG
- AI 生成图生图素材后，用 `scripts/process_skins.py` 批量抠图 + 对齐 + 缩放（依赖 rembg）
- 提示音替换 `assets/sounds/drink.wav`（喝水）和 `assets/sounds/msg.wav`（消息提醒）
